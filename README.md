# BridgeLabz-Training

## 📅 Day 1 – DBMS Fundamentals & RDBMS Basics
- Learned the fundamentals of Database, DBMS, and RDBMS.
- Compared Relational and Non-Relational databases with their use cases.
- Explored MySQL basics along with DDL and DML commands.
- Set up the MySQL environment and started designing the Health Clinic ER Diagram.

---

## 📅 Day 2 – ER Diagram, Indexing & Normalization
- Studied ER Diagram concepts including entities, relationships, and cardinality.
- Learned database indexing and its impact on query performance.
- Understood normalization (1NF, 2NF, 3NF, BCNF) to reduce redundancy.
- Finalized the Health Clinic ER Diagram and normalized the database schema.

---

## 📅 Day 3 – Joins, Stored Procedures & Triggers
- Practiced SQL Joins including Inner, Left, Right, and Full Outer Joins.
- Learned how Stored Procedures improve code reusability and performance.
- Explored Triggers for automating database operations.
- Implemented joins, procedures, and triggers for the Health Clinic database.

---

## 📅 Day 4 – JDBC & Health Clinic Application
- Learned how JDBC connects Java applications with MySQL.
- Implemented CRUD operations using JDBC and understood connection pooling basics.
- Integrated the Health Clinic database with a Java console application.
- Completed and tested the Health Clinic Management System.
